      The network under test: the satellite is the cell tower

      Each row does the same job on both sides. Skylo's satellite, ground gateway and cloud vRAN together play the role of the tower, and Skylo's core joins the carrier's network as a roaming partner. The release gate above validates every row on the right.

      Dots show one text message travelling each path. The satellite path is slower on purpose: about 540 ms round trip versus tens of milliseconds.

      What stays the same

      • Same phone, same SIM, same 3GPP signaling (attach, authentication, SMS).
      • The phone sees Skylo as just another cell on another network, the way it sees a roaming partner.
      • Verizon's subscriber record (HSS/UDM) still authenticates the user, and texts still reach Verizon's messaging systems.

      What changes

      • Distance: a tower is 1–10 km away; a GEO satellite is ~36,000 km up, so ~270 ms each way.
      • The base station runs in Skylo's cloud, not at a mast, and has to absorb long delay, Doppler and timing advance (3GPP Release 17 NTN).
      • Low data rates (NB-IoT NTN): built for SOS, SMS and IoT, not video.

      Why it matters for System Test

      • Every row on the right is something to validate: device certification, link emulation, vRAN, core, roaming interconnect.
      • The roaming link into Verizon is the partner gate: Verizon must accept a Skylo change before customers see it.
      • Your Verizon experience covers the left side; the right side reuses the same rows.
